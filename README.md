# فلتر تاسي الفني

منصة لفحص أسهم السوق السعودي بنظام نقاط من 100، تجمع ست عائلات من الشروط الفنية (الاتجاه، الزخم، القوة النسبية، الحجم والتجميع، انضغاط التقلب، الاختراق) مع عقوبات للتمدد، واختبار تاريخي مدمج. البيانات تُجلب وتُحدَّث تلقائياً كل يوم تداول بلا أي تدخل منك.

> أداة تحليلية تعليمية وليست توصية استثمارية.

---

## كيف تعمل

```
GitHub Actions (يومياً 4:00 م بتوقيت الرياض، الأحد–الخميس)
   └─ fetch_data.py  ← يجلب الأسعار من Yahoo Finance (واحتياطياً EODHD)
         └─ data/prices/*.json + data/meta.json
               └─ index.html على GitHub Pages ← تفتحه من أي جهاز
```

- **كل جمعة** يشغّل النظام اكتشافاً للأسهم المدرجة حديثاً ويضيفها، ويعيد جلب التاريخ كاملاً لضمان صحة تعديلات التوزيعات والتجزئة.
- إذا لم توجد بيانات بعد، تعرض المنصة **بيانات تجريبية** مع تنبيه واضح.

## الإعداد (مرة واحدة، حوالي 15 دقيقة)

### 1) إنشاء المستودع
1. سجّل الدخول في [github.com](https://github.com) (أو أنشئ حساباً مجانياً).
2. اضغط **New repository**، وسمّه مثلاً `tasi-screener`.
3. اختر **Public** (النشر المجاني على GitHub Pages يتطلب مستودعاً عاماً)، ثم **Create repository**.

### 2) رفع الملفات
1. فك ضغط الملف الذي استلمته.
2. في صفحة المستودع اضغط **uploading an existing file** (أو **Add file → Upload files**).
3. اسحب **كل محتويات** المجلد (وليس المجلد نفسه) إلى الصفحة، ثم **Commit changes**.

> **مهم:** مجلد `.github` مخفي في بعض الأنظمة.
> - على ماك: في Finder اضغط `Cmd + Shift + .` لإظهاره.
> - على ويندوز: في المستكشف اختر **عرض → العناصر المخفية**.
>
> تأكد بعد الرفع أن المستودع يحتوي المسار `.github/workflows/update-data.yml`. إن لم يظهر، أنشئه يدوياً: **Add file → Create new file**، اكتب الاسم `.github/workflows/update-data.yml`، والصق محتوى الملف. وكرر الأمر نفسه مع `pages.yml`.

### 3) تفعيل الصلاحيات والنشر
1. **Settings → Actions → General** ثم في الأسفل **Workflow permissions** اختر **Read and write permissions** واحفظ.
2. **Settings → Pages** ثم في **Source** اختر **GitHub Actions**.

### 4) التشغيل الأول
1. افتح تبويب **Actions**. إن ظهرت رسالة تفعيل الـ workflows فاضغط زر التفعيل.
2. اختر **تحديث بيانات تاسي** من القائمة، ثم **Run workflow**، واختر `discover`، ثم **Run workflow**.
3. التشغيل الأول يستغرق عادة بين 10 و25 دقيقة (اكتشاف الأسهم وتحميل 10 سنوات من البيانات).

### 5) فتح المنصة
بعد انتهاء التشغيل بنجاح (علامة خضراء)، افتح:

```
https://اسم-المستخدم.github.io/tasi-screener/
```

ستجد الرابط أيضاً في **Settings → Pages**. احفظه في المفضلة أو على الشاشة الرئيسية للجوال. من الآن تتحدث البيانات تلقائياً.

## مصدر احتياطي (اختياري)
Yahoo Finance مجاني لكنه غير رسمي، وقد يتوقف أحياناً. لإضافة مصدر احتياطي مرخّص:
1. اشترك في [EODHD](https://eodhd.com) وتأكد أن خطتك تشمل **السوق السعودي**.
2. في المستودع: **Settings → Secrets and variables → Actions → New repository secret**.
3. الاسم: `EODHD_API_KEY`، والقيمة: مفتاحك.
4. راجع رمز المؤشر في `config.json` (الحقل `fallback.index_symbol`) حسب توثيق المزوّد.

يتحول النظام للمصدر الاحتياطي تلقائياً لأي سهم يفشل جلبه من Yahoo.

## الملف اللحظي من تيكرشارت (Excel)

المنصة تستقبل ملف لقطة السوق بأعمدة: **الرمز، الاسم، الإغلاق، التغير، التغير %، صافي السيولة، التاريخ** (مثل الملف المصدّر من تيكرشارت). يُتعرف عليه تلقائياً من العناوين، ويقبل Excel أو CSV، والأعمدة الإضافية مثل الكمية والقيمة اختيارية.

يضيف الملف إلى المنصة:
- **عمود السعر اللحظي** ونسبة التغير.
- **عمود صافي السيولة** مع فلتر «سيولة صافية موجبة».
- **شارة «اختراق»** حين يتجاوز السعر اللحظي أعلى قمة لآخر 20 جلسة، مع فلتر خاص بها. هذا تنبيه مبكر أثناء الجلسة قبل أن يظهر الاختراق في بيانات الإغلاق.
- **بطاقتان في الملخص:** أسهم 70+ بسيولة صافية موجبة، وأسهم 70+ عليها اختراق لحظي.
- **الأسماء العربية** للأسهم.

**طريقتان للرفع:**
1. **سريعة، من المنصة:** زر «رفع ملف» في الأعلى. تظهر الأعمدة فوراً وتُحفظ في متصفحك حتى ترفع ملفاً أحدث أو تضغط «إزالة الملف».
2. **دائمة، من GitHub:** ارفع الملف إلى مجلد `inbox` في المستودع (**Add file → Upload files**، واكتب `inbox/` قبل الاسم إن لم يكن المجلد ظاهراً). سيعمل التحديث تلقائياً فيقوم بـ:
   - تعريب أسماء الأسهم في `symbols.json`.
   - إضافة أي سهم في الملف غير موجود في القائمة، وجلب تاريخه.
   - نشر اللقطة لتظهر لك على أي جهاز.
   - حفظ نسخة يومية في `data/snapshots/` لبناء سجل صافي السيولة مستقبلاً.

> **لماذا لا يدخل صافي السيولة في الدرجة؟** لأنه رقم ليوم واحد بلا تاريخ، فلا يمكن اختبار أثره تاريخياً، وإدخاله يجعل الدرجة غير قابلة للمقارنة مع الاختبار التاريخي. لذلك يُعرض كطبقة تأكيد منفصلة. بعد تراكم عدة أشهر من الملفات اليومية في `data/snapshots/` يمكن اختباره وإضافته كشرط.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | المنصة كاملة (ملف واحد) |
| `fetch_data.py` | جامع البيانات |
| `symbols.json` | قائمة الأسهم وأسماؤها وقطاعاتها |
| `inbox/` | ضع فيه ملف تيكرشارت اللحظي لتعريب الأسماء وإضافة الأسهم ونشر اللقطة |
| `config.json` | إعدادات الجلب (تاريخ البداية، نطاقات الاكتشاف، المصدر الاحتياطي) |
| `.github/workflows/update-data.yml` | الجدولة اليومية والأسبوعية والنشر |
| `.github/workflows/pages.yml` | إعادة النشر عند تعديل ملفات المنصة |
| `data/report.json` | تقرير آخر تحديث: الأسهم الفاشلة، الحركات المشبوهة، إعادات الجلب |
| `src/` و`build.py` | الكود المصدري للمنصة (للمطورين: `python build.py` يعيد بناء `index.html`) |

### تعديل أسماء الأسهم
الأسهم المكتشفة تلقائياً تظهر باسمها الإنجليزي وقطاع «غير مصنف». لتعريبها افتح `symbols.json` على GitHub، واضغط أيقونة القلم، وعدّل `"n"` (الاسم) و`"sec"` (القطاع). لاستبعاد سهم أضف `"exclude": true`.

## استخدام المنصة

- **النتائج:** ترتيب الأسهم حسب الدرجة، مع أعمدة العائلات الست والتصفية بالقطاع والتصنيف والتصدير إلى CSV.
- **تفاصيل السهم:** الرسم البياني بالمتوسطات ومستوى الاختراق، وتفصيل كل شرط: ما تحقق وما لم يتحقق، والعقوبات.
- **الاختبار التاريخي:** دخول على افتتاح اليوم التالي، ووقف وهدف بـ ATR، وعمولة وانزلاق، ونتائج منفصلة داخل العينة وخارجها، وتحليل مساهمة كل عائلة.
- **الإعدادات:** أوزان العائلات، حد السيولة، شدة العقوبات، فلتر حالة السوق، ومعاملات الاختبار. تُحفظ في متصفحك.
- **رفع ملف:** يقبل ملف تيكرشارت اللحظي (انظر القسم أعلاه)، أو ملفات أسعار تاريخية كخطة طوارئ إن تعطل التحديث التلقائي. يقبل ملفات مصدّرة من TradingView أو TickerChart (أعمدة التاريخ والافتتاح والأعلى والأدنى والإغلاق والحجم). سمِّ ملف المؤشر بحيث يحتوي `TASI`.

## حل المشكلات

| المشكلة | الحل |
|---|---|
| المنصة تعرض «بيانات تجريبية» | التشغيل الأول لم ينتهِ أو فشل. راجع تبويب Actions. |
| فشل الـ workflow في خطوة «حفظ البيانات» | لم تُفعَّل **Read and write permissions** (الخطوة 3). |
| فشل خطوة النشر deploy | تأكد أن **Pages → Source** مضبوط على **GitHub Actions**. |
| تنبيه «البيانات متأخرة» | افتح Actions وتحقق من آخر تشغيل. GitHub يوقف الجدولة في المستودعات العامة بعد 60 يوماً بلا نشاط؛ أعد تفعيلها من صفحة الـ workflow إن حدث ذلك. |
| أسهم كثيرة فاشلة في `data/report.json` | غالباً حظر مؤقت من Yahoo. يحاول النظام مجدداً في اليوم التالي، أو أضف المصدر الاحتياطي. |

### التشغيل على جهازك (اختياري)
```bash
pip install -r requirements.txt
python fetch_data.py --discover --full
python -m http.server 8000
# ثم افتح http://localhost:8000
```
فتح `index.html` مباشرة بالنقر المزدوج لن يقرأ مجلد البيانات بسبب قيود المتصفح، فاستخدم الخادم المحلي أعلاه.

## حدود يجب معرفتها
- **البيانات يومية وليست لحظية.** مناسبة لفلتر سوينق على الإطار اليومي.
- **تحيز البقاء:** Yahoo لا يحتفظ عادة بتاريخ الأسهم المشطوبة، فنتائج الاختبار التاريخي قد تكون أفضل من الواقع.
- **لا تحسّن الأوزان على كامل البيانات** ثم تصدّق النتيجة. اعتمد على أرقام «خارج العينة».
